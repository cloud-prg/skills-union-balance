# skill-union-balancer

A local utility skill/project to unify skills from multiple platform directories:

- Compute the union of all skills.
- Evenly distribute (replicate) the union into each target directory.
- Optionally run in dry-run mode for preview.

## Quick start

```bash
python3 scripts/unify_skills.py \
  --dirs "/Users/cloud_prg/.claude/skills" "/Users/cloud_prg/.codex/skills" "/Users/cloud_prg/.agents/skills" "/Users/cloud_prg/.cursor/skills-cursor" \
  --mode copy \
  --dry-run
```

Then remove `--dry-run` to apply.
